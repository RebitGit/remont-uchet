# История изменений — АС «Ремонт-Учёт»

Формат по [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).
Версии по [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] — 2026-10-17

Первая стабильная версия. Подготовлена к защите учебной практики.

### Добавлено
- Окно логина с иконкой показа пароля и чекбоксом «Запомнить меня».
- Аутентификация по логину/паролю с хешированием через std::hash.
- Автосоздание пользователя admin/admin при первом запуске.
- Главное окно: сайдбар, хедер с датой и статусом, переключение экранов через wxSimplebook.
- Дашборд с карточками статистики и таблицей заказов.
- Экран создания заказа с валидацией.
- Экран просмотра заказа: информация, запчасти, статус, история.
- Диалог добавления запчасти в заказ с проверкой остатка.
- Рабочий экран склада: добавление, редактирование, списание, удаление запчастей.
- Поиск по складу и подсветка позиций с низким остатком.
- Генерация PDF-акта приёма-передачи через libharu с блоком условий приёма.
- Экран отчётов: 13 предустановленных периодов + произвольный.
- Экспорт отчётов в CSV с BOM для корректного открытия в Excel.
- Экран администратора: пользователи, роли, настройки, резервное копирование.
- Резервное копирование с автобэкапом (раз в минуту при включённой опции).
- Восстановление БД из выбранной резервной копии.
- Тёмная и светлая темы интерфейса, переключение в настройках.
- Разграничение прав по 4 ролям: оператор, мастер, кладовщик, администратор.
- Журнал операций operation_log.
- Автоматический пересчёт стоимости заказа при списании запчастей.
- Автоматическое удаление заказов со статусом «Выдан» старше 7 дней.
- Модульные тесты на Google Test: test_auth, test_order, test_warehouse.
- Документация: README, BACKLOG, docs/.
- Скрипты: build.bat, run.bat, package.bat.
- Release-сборка с манифестом comctl32 v6.

### Исправлено
- Краткозябры в русских строках — переход на utf8::U().
- Ошибка NOT NULL constraint в part_usage.order_id — разрешён NULL.
- Клик по иконкам в wxListCtrl — создан подкласс ClickableListCtrl.
- Выход из аккаунта закрывал приложение — скрытое окно-держатель.
- Иконки на тёмном фоне были чёрными — функция loadWhiteIcon.
- PDF не сохранялся по путям с кириллицей — сохранение в папку с латинским путём.
- Ошибка 4133 в HPDF_Page_TextRect — заменено на построчный вывод.
- STATUS_ENTRYPOINT_NOT_FOUND при запуске — пересборка vcpkg через --no-binarycaching.
- Краткозябры в CSV — добавлен BOM EF BB BF.
- Тёмная тема не переключалась без перезапуска — диалог возвращает wxID_RETRY.

### Изменено
- Список периодов в отчётах расширен с 4 до 13 + произвольный период.
- Кнопки тулбара отчётов вынесены на отдельную строку.
- Информация о стоимости заказа разделена на work_cost, parts_cost, total_cost.

## [0.9.0] — 2026-10-10

Предварительная версия. Основной функционал реализован, требовалась отладка.

### Добавлено
- Первичная реализация всех экранов.
- Подключение к SQLite через нативные запросы.
- Репозитории для всех сущностей.

### Известные проблемы
- PDF не сохранялся по путям с кириллицей.
- Краткозябры в отчётах.
- Ошибки запуска из-за конфликта версий vcpkg и GCC.

## [0.1.0] — 2026-09-28

Первый черновик. Работа только с базой данных, без UI.

### Добавлено
- Схема SQLite: users, clients, devices, orders, parts, part_usage, operation_log.
- Сидирование тестовых данных.
- Базовый класс DatabaseManager.
