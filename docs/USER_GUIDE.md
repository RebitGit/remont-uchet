# Руководство пользователя

## Что это

АС «Ремонт-Учёт» — приложение для сервисных центров по ремонту электроники. Учёт заказов, склад запчастей, печать актов, отчёты.

## Установка

1. Скачать архив Remont_Uchet.zip.
2. Распаковать в папку без кириллицы в пути (например, D:\Remont_Uchet\).
3. Запустить Remont_Uchet.exe.

Отдельная установка не нужна. База данных создаётся автоматически при первом запуске.

## Вход

При первом запуске создаётся пользователь admin/admin.

## Роли

| Роль | Доступные разделы |
|---|---|
| Администратор | Заказы, Склад, Отчёты, Администрирование |
| Мастер | Заказы, Мои заказы |
| Кладовщик | Заказы, Склад |
| Оператор | Заказы |

## Раздел «Заказы»

Главный экран. Содержит:

- 4 карточки статистики.
- Тулбар: поиск, фильтр, экспорт, кнопка нового заказа.
- Таблица заказов.

### Создание заказа

Кнопка «+ Новый заказ». Заполнить поля: ФИО клиента, телефон, модель устройства — обязательны. Остальные по желанию.

### Просмотр заказа

Клик по строке таблицы. Открывается карточка с информацией, запчастями, статусом и историей.

### Смена статуса

Выбрать новый статус, нажать «Сменить статус».

### Добавление запчасти

Кнопка «Добавить». Выбрать запчасть, ввести количество. Остаток уменьшится, стоимость заказа пересчитается.

### Печать акта

Кнопка «Печать акта». PDF сохраняется под именем act_номер.pdf и открывается.

## Раздел «Склад»

Таблица запчастей.

### Добавление

Кнопка «+ Добавить позицию». Заполнить: артикул, наименование, количество, мин. остаток, цена.

### Редактирование

Иконка карандаша в строке.

### Списание

Иконка минуса. Ввести количество.

### Удаление

Иконка корзины. Подтвердить.

Позиции с остатком ниже минимального подсвечены красным.

## Раздел «Отчёты»

4 типа: заказы по статусам, расход запчастей, работа мастеров, остатки.

### Период

13 предустановленных вариантов плюс произвольный с полями «С: / По:».

### Экспорт

Кнопка «Экспорт в Excel» — сохранить в CSV.

Кнопка «Печать» — сохранить отчёт в PDF.

## Раздел «Мои заказы»

Только для роли Мастер. Видны назначенные заказы.

## Раздел «Администрирование»

4 вкладки.

### Пользователи

Таблица. Кнопка «Добавить». Правый клик по строке: сменить роль, сбросить пароль, отключить/включить, удалить.

### Роли и права

4 карточки с описанием возможностей.

### Настройки

Название сервисного центра, телефон, адрес, email. Кнопка сохранить.

### Резервное копирование

Создать резервную копию, включить автобэкап. Таблица копий. Правый клик — восстановить, открыть папку, удалить.

## Резервное копирование

Копии в папке backups/.

Автоматическое: раз в минуту проверка, одна копия в день, после 8:00.

Ручное: кнопка в администрировании.

Восстановление: правый клик по копии — восстановить.

## Настройки

Шестерёнка в сайдбаре. Тема (светлая/тёмная), путь к БД, путь к бэкапам, автобэкап, смена пароля.

## Выход

Кнопка «Выйти» внизу сайдбара.

## Устранение проблем

### Не запускается
Проверить, что все DLL из архива лежат рядом с exe.

### Кракозябры
Переустановить из архива.

### Не сохраняется PDF
Запустить из папки с правами на запись. Путь без кириллицы.

### Забыт пароль администратора
Удалить data/remont_uchet.db, запустить приложение. Все данные потеряются.

### Потеря данных
Восстановить из последней копии в backups/.

## Удаление

Закрыть приложение, удалить папку.
