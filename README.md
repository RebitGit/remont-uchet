# Ремонт-Учёт

Система учёта заказов сервисного центра по ремонту электроники.

## Требования

- Windows 10 или 11 (64-бит)
- Свободное место на диске: 200 МБ
- Разрешение экрана: не менее 1280×720

## Установка

1. Скачать архив `Remont_Uchet.zip`
2. Распаковать в папку без кириллицы в пути
3. Запустить `Remont_Uchet.exe`

## Первый запуск

- Создаётся база данных `data/remont_uchet.db`
- Создаётся пользователь `admin` с паролем `admin`
- Добавляются демонстрационные данные

## Вход

- Логин: `admin`
- Пароль: `admin`

## Возможности

- **Заказы**: создание, просмотр, смена статуса, печать акта
- **Склад**: добавление, редактирование, списание, удаление запчастей
- **Отчёты**: заказы за период, выручка, загрузка мастеров, остатки
- **Администрирование**: пользователи, роли, настройки, резервное копирование

## Роли

- **Администратор** — все разделы
- **Мастер** — заказы и мои заказы
- **Кладовщик** — заказы и склад
- **Оператор** — только заказы

## Резервное копирование

- Автоматическое: раз в минуту при включённой опции
- Ручное: раздел Администрирование → Резервное копирование
- Восстановление: правый клик по копии → Восстановить

## Устранение проблем

### При запуске ошибка «Точка входа в процедуру не найдена»
Причина: не найден manifest comctl32 v6. Убедиться, что `app.rc` содержит `#include "wx/msw/wx.rc"` и подключён в CMakeLists.txt.

### Ошибка «Не найден libstdc++-6.dll»
Причина: динамическая линковка MinGW. Решение: флаги `-static-libgcc -static-libstdc++ -static`.

### Не отображаются иконки
Причина: папка `resources/` отсутствует рядом с exe. Скопировать `resources/` в папку с exe.

### Кракозябры в русских строках
Причина: файлы сохранены не в UTF-8. Сохранить все .cpp и .h в UTF-8.

### Не открывается БД
Причина: путь содержит кириллицу. Переместить приложение в папку с латинским путём.

### Не работает печать PDF
Причина: нет прав на запись в папку. Запускать из папки с правами записи.

### Не проходит вход admin/admin
Причина: БД повреждена. Удалить `data/remont_uchet.db` и запустить заново.

## Стек

C++17, SQLite, wxWidgets 3.3, libharu, CMake + Ninja, vcpkg, MinGW-w64 GCC 16.2.0, Google Test.

## Структура

- include/ — заголовки
- src/ — реализации
- tests/ — тесты
- resources/ — иконки и шрифты
- sql/ — схема БД
- docs/ — документация

## Сборка и запуск

build.bat — сборка
run.bat — запуск
ctest --output-on-failure — тесты (в папке build)
