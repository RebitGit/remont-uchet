# Как участвовать в проекте

## Сообщить о баге

1. Открыть Issues на GitHub.
2. Нажать New issue.
3. Выбрать шаблон «Отчёт об ошибке».
4. Заполнить все поля.
5. Приложить скриншоты.

## Предложить улучшение

1. Открыть Issues.
2. Нажать New issue.
3. Выбрать шаблон «Предложение улучшения».
4. Описать идею и пользу.

## Внести изменения в код

### 1. Форкнуть репозиторий

На странице репозитория нажать Fork.

### 2. Клонировать

git clone https://github.com/ТВОЙ_ЛОГИН/remont-uchet.git
cd remont-uchet

### 3. Создать feature-ветку

git checkout -b feature/название-функции

Названия веток: feature/... — новая функция, fix/... — исправление, docs/... — документация, refactor/... — рефакторинг.

### 4. Внести изменения

Изменения по слоям снизу вверх: модель, репозиторий, сервис, UI. Обновить CMakeLists.txt, если добавились .cpp.

### 5. Собрать и проверить

build.bat
cd build
ctest --output-on-failure

### 6. Сделать коммит

git add .
git commit -m "feat: краткое описание"

Префиксы: feat, fix, docs, refactor, test, build.

### 7. Запушить

git push -u origin feature/название-функции

### 8. Открыть Pull Request

На странице форка нажать Compare & pull request.

## Соглашения по коду

Стиль — .clang-format. Проверки — .clang-tidy. Комментарии — Doxygen в публичных методах. Русские строки — через utf8::U(). SQL — только параметризованный.

## Порядок ревью

1. Открыть PR.
2. Дождаться ревью.
3. Исправить замечания.
4. Merge в main.
